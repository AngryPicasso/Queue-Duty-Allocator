# Duty Allocation Tool

A simple web-based tool for automatically generating duty allocations from a list of participants.

## Overview

Manually assigning duties can be repetitive and time-consuming, especially when dealing with multiple people and recurring schedules.

This tool provides a simple interface where users can enter participant names and generate an organized duty allocation automatically.

## Features

- Add participant names through a simple interface
- Automatically generate duty allocations
- Reduce repetitive manual assignment
- Simple and easy-to-use web interface
- Fast results without manual calculations

## Tech Stack

- Python
- Streamlit

## How It Works

1. Enter the names of the participants.
2. Submit the list.
3. The application processes the input.
4. A duty allocation is generated automatically.

## Use Cases

The tool can be adapted for:

- Student duty schedules
- Classroom responsibilities
- Team rotations
- Office tasks
- Event responsibilities
- Other recurring assignment workflows
